# PROTECHTB Lab 2

Predajná landing page pre PROTECHTB: IT odolnosť, zálohovanie, bezpečnostný audit a Smart Energy.

## Úpravy obsahu

Najčastejšie zmeny rob v `content.js`: čísla v `proof`, balíky v `solutions`, benefity, Smart Energy kroky, proces a FAQ. Vizuál a responzívne správanie je v `styles.css`. Interakcie, menu, formulár a animácie sú v `script.js`. Štruktúru sekcií upravuj v `index.html`.

## Lokálne spustenie

```bash
python3 -m http.server 8000
```

Potom otvor http://localhost:8000.

## Publikovanie

```bash
git add .
git commit -m "Update landing page"
```
